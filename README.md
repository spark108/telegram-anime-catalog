# Telegram Anime Catalog

Локальный веб-каталог аниме из Telegram. Приложение читает сообщения и метаданные вложений из выбранных источников, распознаёт релизы по настраиваемым правилам и собирает их в карточки тайтлов. Видео и файлы субтитров остаются в Telegram.

## Возможности

- **Источники.** Обычные группы, отдельные темы групп и каналы Telegram. Поиск по названию и `@имени` работает по кэшу. Для каждого источника можно настроить свой JavaScript-анализатор.
- **Каталог.** Поиск по основным и альтернативным названиям, постеры и сведения из Shikimori, фильтры по озвучкам, субтитрам, годам и отслеживанию. Фильтры сохраняются на сервере.
- **Карточки тайтлов.** Сезоны и серии со ссылками на исходные сообщения, общий фильтр материалов и отметки о прочтении для всего тайтла или отдельного сезона. Дубли можно объединить вручную. При совпадении идентификатора Shikimori тайтлы объединяются автоматически.
- **Отслеживание и чёрный список.** Тайтл можно добавить в один из двух списков из меню «⋯». В отслеживании тайтлы с непрочитанными материалами показываются первыми.
- **На проверку.** Сообщения, которые анализатор не смог обработать, можно разобрать вручную и привязать к тайтлу.
- **Публикация.** Выбранное видео или файл субтитров можно отправить в каналы, группы и темы, где у аккаунта есть права на отправку. Поддерживаются пересылка и публикация с подписью из JavaScript-шаблона.

## Установка и запуск

Нужны Node.js **22.13.0 или новее**, npm и аккаунт Telegram. Если получаете проект через Git, выполните:

```sh
git clone https://github.com/spark108/telegram-anime-catalog.git
cd telegram-anime-catalog
```

Из папки проекта запустите команду для своей оболочки.

| Оболочка | Команда |
| --- | --- |
| Windows PowerShell | `.\start.ps1` |
| Windows CMD | `start.cmd` |
| Linux, macOS или WSL | `sh start.sh` |

На запрос порта нажмите Enter, чтобы использовать **8187**, или введите свой порт. Скрипт установит зависимости при первом запуске и проверит их при последующих запусках, в том числе после `git pull`. После запуска сервер останется работать в фоне, а скрипт завершится и по возможности откроет браузер. При необходимости откройте [http://127.0.0.1:8187/](http://127.0.0.1:8187/) вручную. Если выбрали другой порт, укажите его в адресе.

Чтобы видеть вывод сервера прямо в терминале, используйте ручной запуск из папки проекта:

```sh
npm ci
npm start
```

Ручной запуск использует порт 8187, если не задана переменная `ANIME_CATALOG_PORT`. Для остановки нажмите Ctrl+C. При фоновом запуске журнал пишется в `data/server.log`. После обновления кода остановите запущенный экземпляр сервера и снова запустите скрипт.

## Первый вход и подключение источника

1. Откройте [my.telegram.org/apps](https://my.telegram.org/apps), войдите в свой аккаунт и создайте приложение в **API development tools**. Скопируйте **API ID** и **API Hash**.
2. Введите эту пару на экране входа каталога. Войдите по номеру телефона и коду либо выберите вход по QR. Для QR откройте в мобильном Telegram «Настройки → Устройства → Подключить устройство». Если Telegram запросит пароль двухэтапной аутентификации, введите его.
3. Откройте **Источники → Подключить источники**. Вкладка **Чаты** содержит обычные группы без тем, **Группы** — группы с темами, **Каналы** — каналы. Если нужного источника нет, нажмите **Обновить список чатов**.
4. Чтобы выбрать тему, раскройте группу по названию. Отметьте галочками нужные темы и нажмите **Подключить выбранные**. Выбранные пункты сохраняются при переключении вкладок и поиске.
5. Раскройте подключённый источник. Во вкладке **Анализатор** напишите правило или загрузите готовое из списка. Во вкладке **Проверка** можно вручную загрузить примеры сообщений или ввести свои данные. Нажмите **Сохранить и запустить анализ**. Импорт истории начнётся после сохранения анализатора.

Ход импорта и ошибки видны во вкладке **Состояние**. Кнопка **Отвязать источник** останавливает его синхронизацию. Загруженные материалы, анализатор и прогресс импорта сохраняются при повторном подключении.

### Анализаторы

Готовые анализаторы находятся в папке [`analyzers/`](analyzers/). Чтобы добавить свой вариант в список, положите туда файл `.js`. Функция `analyze({ text, attachments })` получает текст или подпись сообщения и метаданные вложений. Она возвращает объект с полями тайтла, например `title`, `season`, `episode`, `year` и `voiceover`. Для неизвестных значений можно вернуть `null`. Пример готового правила есть в [`analyzers/fortuna.js`](analyzers/fortuna.js).

## Публикация

1. В разделе **Публикация** отметьте места назначения и сохраните настройки.
2. При необходимости отредактируйте шаблон подписи и проверьте результат кнопкой **Проверить** на примере JSON. Кнопка **Сбросить шаблон** загружает исходный вариант в редактор. Чтобы применить его, сохраните настройки.
3. Откройте нужную серию в каталоге и воспользуйтесь действием публикации рядом с видео или файлом субтитров.

По умолчанию обе галочки пересылки сняты, и приложение применяет шаблон. **Пересылать с исходной подписью** сохраняет текст исходного сообщения. **Пересылать с исходным автором** включает обычную пересылку и имеет приоритет над настройкой подписи.

Шаблон по умолчанию хранится в [`templates/caption.js`](templates/caption.js) и записывается в базу при первом запуске. Функция `caption(data)` возвращает массив строк. Шаблон пропускает отсутствующие номера сезона и серии и добавляет хештеги в последней строке после пустой строки. Готовые хештеги доступны в `data.hashtags.title` и `data.hashtags.voiceover`.

## Данные и доступ

- После успешного входа **API ID** и **API Hash** сохраняются в `.env` в корне проекта. Если пары нет или Telegram отклонит её, интерфейс попросит ввести данные. Старая пара остаётся в файле до успешной замены.
- Каталог, настройки и сессия Telegram хранятся в `data/catalog.sqlite`. Переменная `ANIME_CATALOG_DATA` позволяет задать другой каталог для данных и журнала. Для резервной копии остановите сервер и скопируйте папку данных и `.env` в защищённое место. По умолчанию Git игнорирует эти пути.
- Для входа с другого устройства в локальной сети откройте адрес компьютера с запущенным сервером и укажите ключ из раздела **Источники → Ключ доступа с другого устройства** на компьютере с сервером.
